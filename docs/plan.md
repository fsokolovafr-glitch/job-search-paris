## 2. Обработка новой вакансии (пошагово)

```
1. Claude выдаёт список новых вакансий
      ↓
2. Faina читает → отмечает "интересно / нет"
      ↓
3. Для интересных: Claude разбирает вакансию (требования, стек, культура)
      ↓
4. Claude выбирает версию CV из Master_CV_Tracks.md
      ↓
5. Claude адаптирует CV под конкретную JD
      ↓
6. Faina проверяет и одобряет → отправляет отклик
      ↓
7. Запись в private/applications.json + обновление дашборда
```

## 3. CV-адаптация

### Алгоритм работы Claude
1. Получить текст/ссылку на вакансию
2. Определить трек (1 = MOps/Automation, 2 = Growth/DemGen) по ключевым словам
3. Открыть `Master_CV_Tracks.md` → выбрать базовую версию под трек
4. Сравнить требования JD с достижениями в Master CV
5. Переформулировать топ-3 достижения под язык вакансии
6. Выделить релевантные инструменты (HubSpot, Salesforce, GA4, и т.д.)
7. Проверить: длина ≤ 1 страница (трек 2) или ≤ 2 страницы (трек 1)
8. Экспортировать в `.pdf` через skill `pdf` или `.docx` через skill `docx`

### Что НЕ меняется
- Контактные данные (берутся из `private/` — не из публичных файлов)
- Структура и хронология
- Факты и цифры (только перестановка приоритетов)

## 4. Трекинг откликов

### Воронка + действия

| Статус | Следующее действие | Кто |
|--------|-------------------|-----|
| Applied | Ждать 7 дней | — |
| No response (7 дней) | Follow-up письмо (опционально) | Faina |
| Screening | Подготовить pitch 2 мин + вопросы к HR | Claude помогает |
| Interview | Prep: кейсы, вопросы к компании, STAR-истории | Claude помогает |
| Offer | Анализ оффера (зарплата, бенефиты, рост) | Claude помогает |
| Rejected | Запись причины; анализ паттерна после 5+ отказов | Claude анализирует |

### Обновление дашборда
- **Company Wishlist** (карта компаний) — обновляется при изменении статуса компании
- **Dashboard Pipeline** (рабочий трекер) — обновляется при каждом отклике и изменении статуса воронки
- Ежедневно (кроме выходных): Claude делает сводку по новым вакансиям из мониторинга
