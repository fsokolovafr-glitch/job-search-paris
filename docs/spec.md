# spec.md — Спецификация системы поиска работы

> **Уровень**: что именно должно работать (не зачем и не как именно реализовано)  
> **Связанные файлы**: `docs/intent.md` (зачем), `docs/plan.md` (как)  
> **Последнее обновление**: 2026-10-30

---

## 1. Мониторинг вакансий

### 1.1 Источники
Только три источника, больше не добавлять:
- LinkedIn Jobs
- Indeed France
- Welcome to the Jungle

### 1.2 Поисковые треки

**Трек 1 — Marketing Ops / Automation**
- Ключевые слова: `Marketing Operations`, `Marketing Automation`, `RevOps`, `HubSpot`, `Marketo`, `CRM Marketing`, `MOps`
- Уточнители: `B2B`, `SaaS`, `technology`
- Локация: Paris, France (+ remote FR, явно указан jobLocation France)
- Формат контракта: CDI или CDD (берём оба)

**Трек 2 — Growth / Demand Generation**
- Ключевые слова: `Demand Generation`, `Growth Marketing`, `Performance Marketing`, `Lead Generation`, `ABM`
- Уточнители: `B2B`, `SaaS`, `tech`, `scale-up`
- Локация: Paris, France (+ remote FR, явно указан jobLocation France)
- Формат контракта: CDI или CDD (берём оба)

### 1.3 Фильтры исключения
- Стажировки и alternance — исключать
- Вакансии без указания Франции в локации (кроме явного remote France)

**Не исключать**: вакансии без указания зарплаты, CDD, вакансии только на английском

### 1.4 Целевой профиль кандидата
- Уровень: middle / middle+ / senior
- Опыт: 7+ лет
- Французский: не обязателен, уровень B1/B2 достаточен

### 1.5 Периодичность
- Частота: **ежедневно, кроме выходных** (пауза с конца сентября — нужно перезапустить Scheduled Task)
- Формат вывода: список вакансий с полями: название, компания, источник, ссылка, дата публикации, трек (1 или 2), пометка (new / reviewed / applied)

## 2. Два инструмента трекинга (разные назначения)

### 2.1 Company Wishlist (карта компаний)
- **Что это**: артефакт в Claude — карта 120+ целевых компаний Франции
- **Ссылка**: https://claude.ai/artifact/JUZYFXoraZXqr2QESQ8F2v
- **Зачем**: видеть, в каких компаниях хочется работать и что в них происходит
- Поля: название, Track A/B/C, трек роли (1/2), статус (To explore / Found / Applied…), ссылка LinkedIn, комментарий

Трек компании:
- **A** = B2B SaaS/tech (основной)
- **B** = FMCG/retail (вторичный)
- **C** = крупный консалтинг и агентства

### 2.2 Dashboard Pipeline (рабочий трекер)
- **Что это**: HTML-артефакт — рабочий дашборд откликов
- **Зачем**: видеть сколько подано, где отказы, что ещё не подано
- Каждый новый запуск мониторинга → новые вакансии попадают сюда
- Поля: компания, роль, источник, дата подачи, статус воронки

### 2.3 Что обновляется вручную
- Статус после каждого действия (отклик, ответ, отказ)
- Добавление новых компаний из мониторинга

## 3. CV-адаптация

### 3.1 Вход
- Текст или ссылка на вакансию
- Трек (1 или 2) — определяется автоматически по ключевым словам

### 3.2 Источник
- Master CV: `Master_CV_Faina_Sokolova.md` (в Claude проекте)
- Выбор трека из `Master_CV_Tracks.md` — там прописаны версии под каждую роль
- Опыт в summary: **7+ лет** (зафиксировано)

### 3.3 Выход
- Адаптированное CV в формате `.docx` или `.pdf`
- Дизайн по `docs/resume-format.md` (Meta-стиль, синяя шапка, A4, 1 страница)
- Ключевые изменения: приоритет достижений, переформулировка под JD, выделение релевантных инструментов
- Cover letter — опционально, по запросу

### 3.4 Ограничения
- CV не коммитится в GitHub (per AGENTS.md)
- Хранится в `private/` или вне репо

## 4. Трекинг откликов

### 4.1 Где хранится
- Файл: `private/applications.json` (gitignored)
- Дублируется вручную в Dashboard Pipeline

### 4.2 Поля записи
```json
{
  "company": "Название",
  "role": "Название роли",
  "track": 1,
  "source": "LinkedIn | Indeed | WTTJ",
  "applied_date": "YYYY-MM-DD",
  "status": "Applied | Screening | Interview | Offer | Rejected | No response",
  "cv_version": "filename.pdf",
  "notes": "Свободное поле"
}
```

### 4.3 Воронка
```
Applied → No response (7+ дней без ответа → флаг follow-up)
Applied → Screening (ответ HR)
Screening → Interview
Interview → Offer / Rejected
```
