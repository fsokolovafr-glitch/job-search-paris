# Стратегия поиска

Пользователь: Krolik. Результат: воспроизводимый список новых/закрытых маркетинговых
вакансий во Франции, источники и история проверок. Автоматическая подача заявок,
переписка с рекрутерами и оценка кандидатов не входят в задачу.

Треки по исходному заданию: A — Microsoft partners (89), B — enterprise (6),
C — French tech/AI (26). Общий итог заявлен 120, сумма треков 121; shortlist 44.
Списки не предоставлены. До импорта нельзя утверждать, что проверены 44 или 120 компаний.
В репозитории одна предоставленная компания LumApps, без живой проверки.

Минимальное решение: JSON → обычный Python → Brave WebSearch → HTTP GET →
структурированный JobPosting → JSON и Markdown → GitHub Actions → commit/push.
Mock-провайдер позволяет проверить логику без ключей и сетевых запросов.
ИИ-модель для выполнения скрипта не требуется.

Запросы задаются по компании, целевой роли и стране. Результаты рассматриваются
как кандидаты; название компании в сниппете недостаточно. Карьерные страницы
без JobPosting, JS-страницы и неоднозначные объявления уходят в ручную проверку.
Следующее обоснованное расширение после получения списка — прямые ATS-адаптеры
для фактических систем компаний; их наличие сейчас не заявляется.

GitHub публикация зависит от выбранных владельца/видимости. Мониторинг зависит от
Brave API key и заполненного shortlist. Не включать второй планировщик поверх
Actions, чтобы не создавать дубли. Krolik разбирает UNKNOWN и отмечает заявки в JSON/CSV.
